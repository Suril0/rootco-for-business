# Root & Co — For Business

**Root & Co** is a plant-based snack brand bringing traditional Indian-inspired snacks — Murukku, Sev, Makhana, Aloo Bhujia, Jackfruit Chips and more — to modern businesses.

This repository contains the production-ready B2B wholesale landing page built for **Root & Co, For Business**.

### What this page does
- Speaks directly to café owners, office admins, gym managers and co-working space operators
- Focuses on partnership value (reliability, consistency, quality, flexibility) rather than individual products
- Captures business enquiries so a sales rep can follow up within 24 hours
- Single-purpose page — no cart, no catalogue, no checkout

### Brand personality
Grounded, simple, warm and a little playful.  
Confident and approachable — like a supplier you’d actually want to work with.

### Design direction
Modern interpretation of an old Indian home: warm cream backgrounds, deep forest green, terracotta accents, generous whitespace, and subtle traditional motifs used sparingly.

### Tech stack
- React (functional components + hooks)
- Custom CSS / CSS Modules
- Fully responsive
- Client-side form validation + inline success state
